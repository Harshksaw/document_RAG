ℹ️ About Document Portal

Learn how to get the most out of your document tools.

🔎 Document Analysis

Goal: Extract structured data/insights from a PDF.

Upload a PDF file and our system will process it to provide a JSON summary of key metrics, entities, and structure detected within the document.

🆚 Compare Documents

Goal: Detect changes between two versions.

Upload a "Reference" PDF (original) and an "Actual" PDF (new version). We'll generate a page-by-page comparison table highlighting modifications.

💬 RAG Chat

Goal: Interactively query your knowledge base.

Upload multiple PDFs/docs to build a FAISS vector index. You can then ask natural language questions, and the AI will answer based on the context retrieved from your files.

⚙️ Configuration

Tips:

  • Adjust Chunk size for granularity.
  • Toggle Session-based FAISS to keep indexes separate per session.
